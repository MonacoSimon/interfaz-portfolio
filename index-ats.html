PIPELINE — 10 STAGES (Jenkinsfile real)

  • 01Clean up — Limpia contenedores y redes previas
  • 02API Tests — Newman — Colección Postman · reportes JSON + XML + JUnit
  • 03Cypress E2E — Tests de interfaz en Docker · reportes HTML
  • 04JMeter Performance — 20 / 50 / 80 / 100 usuarios · .jtl + dashboard
  • 05OWASP ZAP Security — Análisis de vulnerabilidades · reporte HTML
  • 06LocalStack Init — Levanta infraestructura AWS local
  • 07Cloud Setup — S3 · SQS · DynamoDB · Lambda con boto3
  • postAlways · Upload + Poll — Sube reportes a S3 · consulta SQS para pass/fail · apaga contenedores

ARQUITECTURA AWS (LocalStack)

S3 — qa-reports-coffee-cart

Reportes por suite y fecha. Estructura: suite/YYYYMMDD-HHMMSS/

Lambda — Validación automática

Evalúa umbrales de calidad por suite. Retorna PASS / FAIL.

DynamoDB — qa_executions

Historial de builds con métricas por ejecución para análisis de tendencias.

SQS — Cola de fallos + DLQ

Notificaciones de errores. El pipeline consulta la cola para determinar el build final.
