04

Coffee Cart — Proyecto destacado

Pipeline de QA end-to-end con infraestructura cloud

Este repositorio es la demostración más completa de mis capacidades como QA Automation Engineer. Integra múltiples herramientas de testing en un pipeline automatizado con Jenkins, cada suite corriendo en su propio contenedor Docker, y servicios AWS simulados con LocalStack para almacenamiento y validación de resultados.

Pipeline flow
Jenkins CI/CD
→
Docker Compose
→
Cypress
Newman
JMeter
ZAP
→
AWS LocalStack
E2E

Cypress

Pruebas end-to-end automatizadas sobre la interfaz de Coffee Cart. Corre en contenedor Docker y genera reportes HTML en cada build.

API

Newman

Ejecución CLI de colecciones Postman para validar todos los endpoints REST. Reportes JSON y XML integrados en el pipeline.

PERF

JMeter

Pruebas de carga con 20, 50, 80 y 100 usuarios concurrentes. Análisis de tiempos de respuesta y tasa de error.

SEC

OWASP ZAP

Análisis de seguridad automatizado. Detección de vulnerabilidades y generación de reporte HTML con clasificación por riesgo.

S3

AWS S3

Almacenamiento de reportes organizados por suite y fecha. Bucket qa-reports-coffee-cart con estructura jerárquica.

λ

AWS Lambda

Función de validación automática de resultados. Evalúa umbrales de calidad por suite y retorna PASS/FAIL.

DB

DynamoDB

Historial de ejecuciones del pipeline. Tabla qa_executions con métricas de cada build para análisis de tendencias.

SQS

AWS SQS

Cola de notificaciones de fallos con Dead Letter Queue. Determina el resultado final del build en Jenkins.
